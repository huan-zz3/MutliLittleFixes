编队筛选器

编队筛选器是一个用于 Mount & Blade II: Bannerlord 的单人模式 Mod，用来改进部署界面中原版自带的部队筛选功能。

Bannerlord 原版已经有部队筛选，但原版系统只提供 active / inactive 两种状态。某个筛选器被激活后，满足该筛选条件的士兵只是在分配时拥有更高优先级。编队筛选器保留了这个基本思路，但重新设计了这套逻辑，让筛选器定义的是接收规则，而不只是优先级提示。

为什么逻辑不同

在原版 Bannerlord 中，如果你想创建一个“双手武器”编队，通常需要非常小心地调整权重，才能同时做到：

  • 让所有双手武器士兵都进入这个新编队
  • 又不让其他无关士兵也被拉进来

编队筛选器去掉了大部分这种反复试错。如果某个士兵只被一个编队接收，它就会进入那个编队；如果多个编队都能接收同一种士兵，你就可以用权重来控制它们之间的分配比例。

优点和缺点

  • 优点： 配置完成后，通常就不需要在补充新兵或战后减员之后，反复重新调整冲击部队的权重。
  • 缺点： 由于筛选器更精确，配置时需要更多耐心。如果加了太多筛选条件，筛选器可能无法按预期工作：编队会变得过于严格，导致一些士兵找不到可进入的编队。

功能特性

  • 将每个筛选器从 2 态系统改为 3 态系统：
    • 包含：士兵必须具有这一特征
    • 排除：士兵必须不具有这一特征
    • 任意：不关心该筛选条件
  • 士兵只有在符合所有筛选规则时，才会被编队接收。
  • 为了让一个编队能够包含多种类型的部队，每个编队都可以包含多个小队。部队筛选实际发生在 小队 层级，每个小队都有自己的一组筛选器和权重。
  • 当多个小队或多个编队都能接收同一种士兵时，你可以使用 权重 来控制这些已被接收的士兵如何在它们之间分配。
  • 增加了额外的部队筛选项，包括：
    • 单手武器
    • 双手武器
    • 弓
    • 弩
    • 投石索
  • 如果在设置中启用，也可以将筛选规则应用到增援部队上。
  • 会将编队筛选数据保存到战役存档中，同时不会覆盖 Bannerlord 原版的部署配置。

支持的游戏版本

  • Bannerlord v1.4.6。

DLC 兼容性

  • 与海战 DLC 不冲突，但未对海战部署做出任何改动。

依赖项

启用编队筛选器前，请先安装并启用以下依赖：

  • Bannerlord.Harmony
  • Bannerlord.ButterLib
  • Bannerlord.UIExtenderEx
  • Bannerlord.MBOptionScreen（MCM）

安装

  1. 下载 Mod 压缩包。
  2. 将 FormationFilter 解压到 Bannerlord 的 Modules 目录中。
  3. 如果需要，解除 Modules\FormationFilter\bin 目录下 dll 文件的阻止状态。
  4. 确保所需依赖 Mod 已正确安装并启用。
  5. 在 Bannerlord 启动器中启用 FormationFilter。

使用方法

  1. 进入一场会显示部署界面的战斗。
  2. 在每个编队中配置一个或多个小队。
  3. 为每个小队设置筛选器，以定义它能接收哪些士兵。
  4. 一般来说，你应该保留一个不设筛选器、权重为 0 的默认编队，并为其他特殊编队（冲击部队、标枪部队等）设置筛选器和最大权重。
  5. 当多个小队或编队都能接收同一批士兵，并且你希望控制它们之间的分配时，再调整权重。
    • 小队人数提示例如 50 / [20, 80]，表示该小队当前有 50 名士兵。如果你只调整权重而不改变筛选器，则该小队预计的最小/最大人数分别为 20 和 80。
    • 将鼠标悬停在某个编队上时，工具提示会显示该编队中各个小队的筛选详情。按住 Alt 时，还会额外显示相关小队的详情。
  6. 当部署结果符合预期后，开始战斗。

如果有士兵不满足任何已配置的编队筛选条件，Mod 会给出提示。如果出现这种提示，通常说明你的筛选条件过于严格。你需要移除一些筛选条件；如果多个编队都能接收同一批士兵，再用权重决定它们如何分配。

示例

  • 如果想筛选出有双手武器且没有盾牌的士兵，可以把双手筛选器设为 包含，把盾牌筛选器设为 排除。

示例：没有盾牌的双手步兵

假设你想让所有使用双手武器但没有盾牌的冲击步兵进入编队 5，而其他所有步兵都留在编队 1。

有两种实现方式：

方式 1：更简单，使用权重分配部队

可以这样设置：

  • 编队 1：不设置任何筛选器，所有筛选器恢复默认，权重设为 0。
  • 编队 5：包含 双手、排除 盾牌，并将权重设为最大。

在这种设置下，没有盾牌的冲击步兵可能同时满足编队 1 和编队 5，但由于编队 1 的权重是 0，它们最终都会进入编队 5。

方式 2：更复杂，但更精确

如果你熟悉集合论，可以这样设置：

  • 编队 1：包含 盾牌。这样会选择所有持盾部队，不管他们是否也带有双手武器。
  • 编队 5：包含 双手、排除 盾牌。

设置完成后，可能还会剩下一些既没有盾牌、也没有双手武器的低阶士兵。

如果有，那么编队 1 还需要为这些士兵增加一个小队：

  • 点击编队 1 顶部的右箭头，新建一个小队。
  • 将该小队设为步兵。
  • 将它的筛选器设置为 排除 双手，并且可以按需要再加上 排除 盾牌。

这样就能在不使用权重的情况下得到精确结果：

  • 没有盾牌的双手部队进入编队 5
  • 其他所有步兵进入编队 1
  • 诺德熊皮狂战士也会进入编队 1，因为他们携带盾牌

配置项

可用设置包括：

  • 是否根据编队筛选规则分配增援
  • 是否将可挥砍的长杆武器视为双手武器
  • 是否将投矛视为长杆武器
  • 是否将投矛视为投掷武器
  • 设置高阶与低阶部队的阶级阈值

存档兼容性

编队筛选器会把自己的编队筛选数据写入存档，同时保持原版部署配置不变。

如果之后移除这个 Mod，Bannerlord 将不再读取这部分额外数据。这些筛选配置会在下次保存游戏时丢失，而原版部署行为会自动恢复。

从源码构建

项目位于 source\FormationFilter，使用 MSBuild 构建。

nuget restore .\source\FormationFilter\FormationFilter.slnx
MSBuild.exe .\source\FormationFilter\FormationFilter.slnx /p:Configuration=Release /p:GamePath="C:\Path\To\Bannerlord\"

打包后的模块输出位于 source\FormationFilter\package。
