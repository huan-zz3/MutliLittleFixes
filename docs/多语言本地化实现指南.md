# Bannerlord 模组多语言本地化实现指南

> 适用范围：Mount & Blade II: Bannerlord（骑马与砍杀 II：霸主）单机模组开发。
> 本文以 **Improved Garrisons（驻军管理）** 模组为实际案例，讲解**游戏本体原生本地化系统**的完整用法。

---

## 0. 结论速览：Improved Garrisons 是怎么做多语言的？

**Q1：本 mod 的多语言配置是什么方式？**

答：**完全走游戏本体的原生本地化系统**。代码中所有 UI 文本、菜单、对话都写成 `new TextObject("{=ID}English fallback text")` 形式，由游戏引擎在运行时根据当前语言解析 `{=ID}` 标签。翻译文本存放在 `ModuleData/Languages/CNs/` 目录下的语言 XML 文件中（本 mod 有 724 条中文词条）。

**Q2：走游戏本体处理吗？**

答：**是。** 所有 `{=ID}` 标签字符串全部由游戏引擎的 `TaleWorlds.Localization` 系统处理，mod 自身不需要任何翻译逻辑、不需要任何第三方库。

> 💡 启示：写新 mod 时，多语言**只需要做两件事**——(1) 代码里所有展示文本写成 `new TextObject("{=ID}fallback")`；(2) 在 `ModuleData/Languages/` 下按语言放翻译 XML 文件。游戏启动时自动加载、自动合并、自动随玩家切换语言。

## 1. 游戏本体原生本地化机制

### 1.1 原理

Bannerlord 的本地化由游戏引擎自带的 `TaleWorlds.Localization` 模块实现，核心机制是**字符串 ID 标签**：

```csharp
new TextObject("{=ig_menu_start}Improved Garrison")
```

- `{=ig_menu_start}` —— 字符串 ID（`{=` + ID + `}`）。
- `Improved Garrison` —— **fallback 文本**。当当前游戏语言找不到该 ID 时，直接显示这段英文（所以永远不要留空）。

游戏启动时，引擎会扫描**所有已加载模块**的 `ModuleData/Languages/<语言>/` 目录，把每个模块的语言文件合并进一张全局字符串表。代码里出现 `{=ID}` 时，引擎查表替换为当前语言的译文；查不到就用 fallback 文本。

关键点：**mod 不需要注册任何东西**。只要语言文件放在 `ModuleData/Languages/` 下、结构正确，游戏自动加载 —— 这也是为什么 Improved Garrisons 的 `SubModule.xml` 里 `<Xmls/>` 是空的。

### 1.2 目录结构与文件格式

标准结构（Improved Garrisons 实际使用的就是这一套）：

```
ImprovedGarrisons/
├── SubModule.xml
├── bin/Win64_Shipping_Client/ImprovedGarrisons.dll
└── ModuleData/
    └── Languages/
        ├── English/                          ← 每种语言一个文件夹
        │   ├── language_data.xml
        │   └── std_module_strings.xml        ← 词条文件（文件名随意）
        └── CNs/                              ← 简体中文
            ├── language_data.xml
            └── std_module_strings_zho-CN.xml
```

#### (1) `language_data.xml` —— 语言声明文件

```xml
<?xml version="1.0" encoding="utf-8"?>
<LanguageData id="English" name="English" subtitle_extension="en-GB"
              supported_iso="en-GB,en-US,en,eng,en-us,en-gb,en-au"
              under_development="false">
  <LanguageFile xml_path="English/std_module_strings.xml"/>
  <LanguageFile xml_path="English/std_module_more_strings.xml"/>
</LanguageData>
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 语言标识，**必须与游戏原生语言 ID 完全一致**（如 `English`、`简体中文`），否则游戏不会把它当成「当前语言」加载。 |
| `name` | 建议 | 语言显示名。 |
| `subtitle_extension` | 可选 | 字幕文件扩展名（如 `en-GB`、`zh-HANS`），用于过场动画字幕。 |
| `supported_iso` | ✅ | 支持的 ISO 语言码列表，游戏用它匹配玩家选择的语言。 |
| `under_development` | 可选 | `true` 表示该语言仍在开发中（游戏中会显示警告）。 |
| `<LanguageFile xml_path="..."/>` | ✅ | 词条文件路径，**相对于 `Languages/` 目录**。可多个。 |

#### (2) 词条文件 —— 真正的翻译内容

TaleWorlds GameSystem XML 格式：

```xml
<?xml version="1.0" encoding="utf-8"?>
<base xmlns="http://schemas.taleworlds.com/2007/04/GameSystem/" type="string">
  <tags>
    <tag language="English"/>
  </tags>
  <strings>
    <string id="ig_menu_start" text="Improved Garrison"/>
    <string id="ig_menu_manage" text="Manage your Improved Garrisons"/>
  </strings>
</base>
```

- `<base>` 的 `xmlns` 和 `type="string"` **缺一不可**，这是 TaleWorlds 序列化器识别的凭据。
- `<tags><tag language="X"/></tags>` 声明词条所属语言。
- `<string id="..." text="..."/>` 一行一条词条。
- `text` 内换行用 `&#10;` 转义。

Improved Garrisons 的真实文件摘录（`ModuleData/Languages/CNs/[DLL-本地化] ImprovedGarrisons.dll.xml`）：

```xml
<base xmlns="http://schemas.taleworlds.com/2007/04/GameSystem/" type="string">
  <tags>
    <tag language="简体中文"/>
  </tags>
  <strings>
    <string id="misc_ig_onmapload" text="驻军管理模组已加载。"/>
    <string id="tutorial_title" text="驻军管理教程"/>
    <string id="menu_start" text="驻军管理"/>
    <string id="dialog_end_nice" text="很好，继续吧。再会。"/>
    ...
  </strings>
</base>
```

它的 `language_data.xml`（注意路径写法）：

```xml
<LanguageData id="简体中文">
  <LanguageFile xml_path="CNs/[DLL-本地化] ImprovedGarrisons.dll.xml"/>
</LanguageData>
```

### 1.3 代码中的用法

#### (1) 最常用：`new TextObject("{=ID}fallback")`

所有**展示给玩家**的文本都应包一层 `TextObject`：

```csharp
// 菜单项 —— Improved Garrisons/MainMenu.cs 的真实写法
gameStarter.AddGameMenuOption(
    "town_keep", "town_garrison_options",
    new TextObject("{=menu_start}Improved Garrison", null).ToString(),
    condition, consequence);

// 顶部提示信息
InformationManager.DisplayMessage(
    new InformationMessage(
        new TextObject("{=info_global_conf}You are now editing the settings of", null).ToString(),
        Color.FromUint(ModuleColors.modMainColor)));

// 对话
starter.AddDialogLine("recruit_talk", "start", "recruit_talk",
    new TextObject("{=dialog_recruit_start}Greetings, my Lord!", null).ToString(), ...);
```

#### (2) 带变量的文本：`{VAR}` + `SetTextVariable`

```csharp
TextObject text = new TextObject("{=ig_party_destroyed}Your party {PARTY_NAME} has been destroyed.", null);
text.SetTextVariable("PARTY_NAME", partyName);
string result = text.ToString();   // 自动本地化 + 变量替换
```

也可以在构造函数里直接传变量字典：

```csharp
var attributes = new Dictionary<string, object> { { "PARTY_NAME", partyName } };
new TextObject("{=ig_party_destroyed}Your party {PARTY_NAME} has been destroyed.", attributes);
```

#### (3) 直接按 ID 查文本：`GameTexts.FindText`

```csharp
// Improved Garrisons/BuildingVM.cs 的真实用法 —— 复用游戏原生的词条
TextObject explanation = GameTexts.FindText("str_town_management_reserve_explanation", null);
```

> 可以复用游戏原生词条（`str_*`、`menu_*` 等），但**强烈建议查词条 ID 前先确认语义吻合**，避免错译。游戏原生的 ID 可以从 `Modules/Native/ModuleData/Languages/English/std_*.xml` 里查到。

#### (4) UI（Gauntlet）ViewModel

自定义 UI 的文本流是：**代码 → ViewModel 属性 → Prefab 绑定**。文本依然在 C# 侧用 `{=ID}` 生成，Prefab 只负责显示：

```csharp
// Improved Garrisons/TrainingUIVM.cs 的真实写法
public string TrainingSettingsText { get; } = new TextObject("{=ui_trainingui_trainingsettings}Training settings", null).ToString();

public HintViewModel AddTroopsButtonHint { get; } =
    new HintViewModel(new TextObject("{=ui_trainingui_addtroopshint}Add new troops to the training template.\n\n...", null), null);
```

```xml
<!-- ImprovedGarrisonsMenu.xml —— Prefab 里只做绑定，不写死文案 -->
<RichTextWidget Text="@Title" Brush="Recruitment.Popup.Title.Text" ... />
```

**规则：文案永远在 C# 里用 `{=ID}` 生成，XML Prefab 里不要出现硬编码英文。**

### 1.4 最佳实践清单

1. **ID 加前缀**：`ig_`、`yourmod_` 等，避免与其它 mod 或游戏原生词条冲突（Improved Garrisons 的部分 ID 如 `menu_start` 其实偏短，是反例，不要学）。
2. **fallback 文本永远写英文**：万一漏译，玩家看到的是可读的英文而不是空串。
3. **文件命名**：`language_data.xml` 固定名；词条文件建议带语言码后缀，如 `std_module_strings_zho-CN.xml`、`std_module_strings.xml`。
4. **编码**：词条文件用 `UTF-8`（带 BOM 更保险）或 `UTF-16`；Windows 记事本/编辑器保存时注意别存成 ANSI，否则中文直接乱码。
5. **XML 转义**：`&` → `&amp;`，`<` → `&lt;`，`>` → `&gt;`，换行 → `&#10;`，制表符 → `&#9;`。
6. **无需注册**：语言文件不要写进 `SubModule.xml` 的 `<Xmls/>`，游戏自动扫描 `ModuleData/Languages/`。
7. **`id` 与游戏语言一致**：中文必须写 `简体中文`（不是 `Chinese`、不是 `CNs`）；繁中是 `繁體中文`。ISO 码按 1.5 节速查表抄。
8. **新增语言只加文件**：新增文件夹 + `language_data.xml` + 词条文件即可，C# 代码一行不用改。
9. **不要按语言切代码分支**：`if (language == Chinese)` 是错误示范。原生系统已经处理了这件事。

### 1.6 验证与测试

1. **结构自查**：语言文件必须位于 `ModuleData/Languages/` 下，`language_data.xml` 的 `<LanguageFile xml_path>` 路径相对 `Languages/` 正确。
2. **进游戏测试**：在主菜单「选项 → 语言」切到目标语言（或直接用启动器设置），再进游戏看 mod 界面。
3. **fallback 验证**：故意把某个 ID 写错，应显示英文 fallback 而不是空白或崩溃。
4. **日志排查**：词条解析失败通常伴随 `TaleWorlds.Localization` 相关异常，看 `Modules/ImprovedGarrisons/ModuleData/ErrorLog.xml`（本 mod 自己的日志）或游戏根目录的 `*.log`。
5. **词条 ID 冲突**：如果别的 mod 用了相同 ID，后加载者覆盖。用独一无二的前缀规避。

## 2. 快速上手清单（新 mod 加中文翻译，5 步）

1. 代码里所有展示文本写成 `new TextObject("{=你的前缀_语义ID}English text", null)`。
2. 新建 `ModuleData/Languages/CNs/language_data.xml`：

   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <LanguageData id="简体中文" name="简体中文" subtitle_extension="zh-HANS"
                 supported_iso="zh-HANS,zh,zho,chi,zh-cn,zh-sg" under_development="false">
     <LanguageFile xml_path="CNs/std_module_strings_zho-CN.xml"/>
   </LanguageData>
   ```

3. 新建 `ModuleData/Languages/CNs/std_module_strings_zho-CN.xml`：

   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <base xmlns="http://schemas.taleworlds.com/2007/04/GameSystem/" type="string">
     <tags>
       <tag language="简体中文"/>
     </tags>
     <strings>
       <string id="你的前缀_语义ID" text="中文译文"/>
     </strings>
   </base>
   ```

4. 想支持更多语言？复制 CNs 文件夹改名 + 改 `id` 和 ISO（见 1.5 速查表）。
5. 进游戏切语言验证。

### 3.1 XML 转义速查

| 字符 | 转义 | 场景 |
|---|---|---|
| `&` | `&amp;` | 文案中的 & 符号 |
| `<` / `>` | `&lt;` / `&gt;` | 文案中的尖括号 |
| 换行 | `&#10;` | 多行提示文本 |
| 制表符 | `&#9;` | 对齐文本 |
| 引号 | 无需转义（在属性值中若用双引号包裹则注意） | —— |
